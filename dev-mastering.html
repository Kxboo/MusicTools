    Advanced — loudness targets & meters

    Loudness targetiPick the loudness target that matches where this master will play — Streaming, Loud (club/radio), or Dynamic. On bounce, output gain is automatically adjusted (and re-measured) so the exported file lands on that Integrated LUFS value. Pick "Custom" to bounce at whatever Output trim you've dialed in, with no auto-matching.

    Short-term LUFS (BS.1770)iA rolling 3-second loudness reading. It responds much faster than Integrated LUFS, so it is useful for spotting loud choruses or quiet verses. —
    Integrated LUFS (gated)iThe overall program loudness using ITU-R BS.1770 gating. Quiet passages below the gates are excluded so silence and long fades do not make the master look artificially quiet. —
    True peak (est.)iEstimates the highest inter-sample peak, which can be higher than visible digital sample peaks after encoding or playback conversion. The ceiling gives this master a safety margin. —
    Dynamic range (crest)iThe difference between peaks and average level. Larger values usually feel more punchy and open; smaller values are denser and more consistently loud. —
    Gain reductioniHow much the compressor and limiter are turning the signal down at this moment. A little movement is normal; heavy, constant reduction can flatten transients. 0.0 dB
    Stereo correlationiHow similar the left and right channels are. +1 is strongly mono-compatible; values near 0 are wide; sustained negative values can partially disappear when played in mono. —

    Live values are rolling estimates. Offline results use the app’s BS.1770-style K-weighted measurement and peak estimator; validate delivery-critical masters in a calibrated external QC meter.
